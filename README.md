# SalesCo Database Project

## 📌 Description

This project contains SQL scripts to create and manage a SalesCo database system.

## 🗂️ Tables Included

* CUSTOMER
* INVOICE
* VENDOR
* PRODUCT
* LINE
* CUSTOMER2

## ⚙️ Features

* Database creation and table setup
* Sample data insertion
* SQL queries for:

  * Aggregation (SUM, COUNT)
  * Joins
  * Filtering
  * Reports

## 🛠️ Tools Used

* SQL Server
* T-SQL

## 📊 Sample Queries

* Total invoice amount
* Customer purchase summary
* Product filtering by vendor
* Sales reports
